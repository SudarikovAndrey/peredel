# Передел — прототип эндгейм-режима

Играбельный прототип режима перепрохождения районов для «Рынка Пацана».
Открывается по адресу https://sudarikovandrey.github.io/peredel/

## Что это

Забег на 72 круга по доске района 10 против залётной банды, которая ходит
одновременно с игроком и играет по тем же правилам. Точки, товар, прокачки
и цены взяты из конфигов кора (`Maps.json`, `Buildings`, `Goods`) — выгрузка
лежит в `district-10.json`.

## Что внутри

- Баланс — объект `CFG` в начале скрипта, всё в одном месте.
- Тест-стенд по кнопке ≡: скорость, читы, прогон партий ботом (10 / 30 / 100),
  накопленные метрики и экспорт.
- Метрики копятся в localStorage браузера: снимок живой партии каждый круг
  и строка на каждый прогон ботом, с хешем конфига. Кнопка «Скопировать всё»
  выгружает партию, историю и события одним JSON.
- Внутри Claude та же сборка публикуется артефактом с общей базой — там партии
  всех игроков стекаются в одно место и разбираются со стороны разработки.

Спецификация режима — в базе знаний ГДД, `черновики/передел/передел-гдд.md`.
